## 2.BibaYanji


知名的电脑博主 “笔吧评测室”，开源了一个电脑验机工具，

它可以一键读取电脑的 CPU、显卡、内存、硬盘、网卡、屏幕、电池 等各种数据，

方便用户和购买时，商家提供的数据做对比，

还可以进行键盘测试、屏幕坏点测试、

摄像头、麦克风、扬声器测试，

散热测试、硬盘跑分等各种测试项目。


因为它是专门为 “对电脑了解不深的用户” 设计的，

所以使用起来很简单，

如果你最近有买新电脑、二手电脑的计划，或许会对你有用。


BibaYanji（笔吧验机）
https://github.com/Bibapcs/BibaYanji

## 3.HowToLiveBetter

这是最近爆火的一个文档类项目，中文名为《高性价比人生指南》，

目的是用最少的钱、时间和精力，换尽量多的寿命、金钱和自由。


它用大量的建议，

帮我们了解怎么少出意外、怎么少生病、怎么自救、怎么少花冤枉钱。

并且每条建议都会写清楚成本和收益。


比如，坐车时一定要系安全带，

成本只需要两秒时间，但是受致命伤的风险下降 45% 以上。


去 KTV、酒吧、密室等场所之前，先看一眼安全出口在哪，

如果被堵死就换一家，只需要十秒的成本，但出意外的时候能帮很大的忙。


发现被骗时，立刻报警要求止付，速度越快追回钱的概率越大。


失业之后，可以在线申请失业保险金，

只要交社保满一年，且不是自己主动辞职，就能申请领取。



我的想法是：

里边很多内容我感觉还是非常有用的，非常建议有时间看一下。

有一些建议虽然是常识，但生活中确实会忽略。


HowToLiveBetter（高性价比人生指南）
https://github.com/eternity4719/HowToLiveBetter


## 4.Mac-Explorer

Mac 的文件管理器 “访达”，

不管是外观还是使用逻辑，都和 Windows 区别很大，

很多习惯了 Windows 的人会用不习惯。


于是，有人模仿 Windows 资源管理器的样式，

做了这个 Mac-Explorer。


我使用了一段时间，确实非常还原，

外观、使用方式、快捷键都几乎一样，体验非常好。


Mac-Explorer（文件管理器）
https://github.com/qixiaoyu27/Mac-Explorer

## 5.Husk

这是一个可以运行在苹果手机上的安卓模拟器，

可以让用户通过转译或者模拟两种方式，在 iOS 上运行 APK 软件。


不过它虽然提供了安装包，但是我没有在 AppStore 中搜到，

所以安装的时候需要一些手段，适合喜欢折腾的用户。


类似的项目还有 madeira，

这是一个苹果手机上的 Windows 模拟器，

拥有原生的 Wine 环境，

可以让用户在 iOS 上运行电脑软件，跑 3A 游戏大作。

Husk（模拟器）
https://github.com/Leviidev/Husk
https://github.com/willfaust/madeira

## 6.yovoice

这是一个开源的文本转语音工具，

它完全本地运行，支持使用各种开源的语音模型，

不同的模型有不同的效果，

比如 IndexTTS，可以克隆音色、控制情绪、参考演绎，

VoxCPM2，可以使用文字设计音色。


不同的音色，能保存成角色，方便生成语音的时候使用。


如果你有语音相关的需求，或许会对你有用。



yovoice（声音生成）
https://github.com/leemysw/yovoice
