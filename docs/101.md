# 【101】2026年5月2日-2026年5月9日

## 1.cc-switch

2026 年的 AI，是 Agent 的时代，

Claude Code、Codex、OpenCode、OpenClaw 各种工具都有很多人用。

但是，一个问题也随之诞生了，

想要在这些工具中随意切换模型，需要经常改配置文件，非常麻烦且浪费时间。

cc-switch 是一个可以帮我们统一管理，Agent 工具模型的开源项目，

比如我要在 Claude Code 上使用 DeepSeek 模型，

就打开 cc-switch，选择 Claude Code，

点击右上角的加号，在这里已经有了非常多的模型供应商，

选一个自己想要的，然后在下边填写 key 等信息，之后点击添加。

就能在模型列表中看到它，并一键使用了。

添加完模型后，我们可以在使用时，随时切换它们，

比如复杂任务使用比较贵的 Claude，简单任务时切换到性价比高的国产模型。

除此之外，通过 cc-switch，我们还能很轻松的查询模型用量，

配置故障转移，在一个模型不稳定、没额度的时候，自动切换到其它模型工作。

cc-switch

https://github.com/farion1231/cc-switch

## 2.DeepSeek-TUI

有人给 DeepSeek，开发了一个专用的终端编程 Agent，

可以写代码、读写本地文件、执行各种命令、搜索浏览网页等等。

目前这个项目在 GitHub 上非常火，几天就拿到了 20 多 k Star。

我的想法是：

最近除了这个 DeepSeek-TUI，另一个叫 DeepCode 的 Agent 也很火。

但说实话，目前各种 Agent 工具实在太多了，AI 厂商基本上人手一个，

开源的也数不胜数，

其实对于普通用户来说，体验差别并没有那么大，功能也都类似，

如果你已经有了顺手的工具，就没有必要折腾。

DeepSeek-TUI

https://github.com/Hmbown/DeepSeek-TUI

## 3.Maigret

输入一个用户名，

它就会从 3000 多个网站上搜索叫这个名字的用户，把它们的主页全部找出来，

最后生成一份报告。

我试了一下，海外平台能搜到的信息很全，国内平台也有一些。

如果你比较在意自己在互联网上的信息，个人建议多准备一些不同的用户名。

maigret

https://github.com/soxoj/maigret

## 4.openreel-video

这是一个开源的剪辑软件，它的目标是代替掉剪映，

根据我的体验来看，它目前剪辑的基础功能已经很齐备了，

并且还有文字转语音、自动生成字幕等 AI 功能，

拿来做一些基础的剪辑没有太大问题，但如果是专业创作，还是需要专业软件。

如果你想学习一下，剪辑软件是怎么开发出来的，可以拿来当做参考。

openreel-video

https://github.com/Augani/openreel-video

VPet
