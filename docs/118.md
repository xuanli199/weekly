## 1.convenient_window_free

在 Mac 上有一个叫触发角的功能，

只要把鼠标移动到屏幕的角落里，就能触发各种功能。


convenient_window_free 是一个可以给 Windows 也增加触发角功能的项目，

我们可以自定义触发位置、方式、触发后执行的动作，

比如我喜欢把右上角设置成直接触发任务视图，右边缘设置成直接触发回到桌面，

也可以根据需要自定义各种快捷键和命令，

使用时只需要动动鼠标，习惯之后会非常方便。


如果不喜欢触发角，也可以用鼠标手势，

设定好之后，长按鼠标右键并画出指定图案，就能执行指定的动作。


除此之外，它还有窗口增强功能，

窗口增强中的贴边隐藏，可以通过把任意窗口拖到边缘，实现贴边收起，

需要的时候鼠标放过去自动还原。

默认情况下，我们调整窗口大小或者位置，需要把鼠标放到窗口边缘，

拖拽与缩放功能打开后，只需要按下 Alt 键，就能在任意位置调整它们。


convenient_window_free（触发角）
https://github.com/ximizhou/convenient_window_free

## 2.Magpie

Magpie 是一个可以给任何窗口增加缩放和滤镜的开源工具，

最近 DLSS5 相关文件泄露后，有人把它和 Magpie 结合了起来，

做出来一个可以给任何窗口添加 DLSS5 效果的工具。


使用时我们需要新建一个缩放模式，

然后添加 DLSSNR AI Filter 和 FrameRate Filter 效果，

之后在看视频、玩游戏的时候，按下快捷键，

或者新建一套配置文件，指定需要添加滤镜的窗口，它的显示效果就会被 DLSS 优化。


不过因为 Magpie 只能捕获颜色画面来估算数据，无法直接对接游戏引擎，

所以效果也比原生的 DLSS5 要差一些，

但优势是不挑游戏，哪怕是放视频都可以使用。

如果你想尝鲜一下，或许会对你有用。


Magpie（给任意窗口加 DLSS5）
https://github.com/Blinue/Magpie

## 3.Highball

这是一个可以让我们在 Mac 电脑上运行 Windows 游戏的开源项目，

它可以根据游戏的不同，配置不同版本的转译层，

并在安装 Steam 或链接 Epic 库后，清晰地告诉用户哪些游戏可以运行、哪些不能运行，

哪个游戏适合哪个渲染器。

如果你有类似的需求，可以试试。


Highball（Mac 玩 Windows 游戏）
https://github.com/gauthierpiarrette/highball

## 4.AI-Cubby

不知道你有没有遇到过这样的场景，

想要找一个使用过的软件，但是忘记了在哪里，又记不清名字是什么，

最后只能凭借仅有的一点点印象去慢慢翻。


再一次因为找软件浪费了半个小时后，AI-Cubby 的开发者一怒之下写了这个软件，

它会记录我们所有打开过的软件和文件，并追踪使用时长和打开次数，给它们自动打标签，

也可以把某个文件夹拖进去交给它。


记录之后就可以通过自然语言在这里搜索，

搜清理电脑，能找出来电脑上能清理的软件和书签；

搜昨天看过的文档，会显示所有的相关内容。


嫌它的自动标签不准，也可以手动对标签和文件打标，

比如花了很长时间，我终于从电脑上找出来了这个叫 Magpie 的软件，

为了下次找起来更方便，就给它标记滤镜，

之后搜滤镜就能把它搜出来。


所以它还具有一点养成的效果，

用的越多、积累的数据越多，会更顺手。


AI-Cubby（软件文件搜索）
https://github.com/miragecoa/AI-Cubby
