## 1.AIHOT

## 2.tubatools


图吧工具箱是一个知名的电脑工具箱，

其中聚合了几十种常见的硬件检测、评分工具。


tubatools 是图吧工具箱的一个开源社区重构版，

可以提供一台新电脑从验机、跑分、装驱动，到日常清理维护的各种帮助。


比如：

这个 CPUZ，就是查看 CPU、主板、内存等硬件信息的权威工具，

DiskGenius 是最经典的硬盘分区工具之一，

FurMark GUI 是非常好用的 GPU 烤机工具。


除此之外，它还有很多自己编写的实用功能，

比如性能测试，可以一键调用各种工具，测试电脑性能，


系统工具中，能通过证书拦截各种流氓软件，

快速清理无用的右键菜单、自启动、计划任务，

下载干净的 Windows 系统镜像。


游戏工具中，可以缓解晕 3D，

监控玩游戏时的帧数、温度、负载，

创建虚拟局域网，和朋友远程联机玩各种游戏。


tubatools（图吧工具箱 CE）
https://github.com/luolangaga/tubatools

## 4.window-switcher


在 Mac 上，如果你同一个软件打开了多个窗口，

可以通过 Command + 波浪键，很方便的在不同窗口间切换，

而 Windows 没有类似的功能，


window-switcher 就是一个可以给 Windows，

增加此功能的开源项目，

打开之后，只需要按下 Alt + 波浪键，

就能很方便的切换同一软件的窗口。


我的想法是：

微软的开源项目 PowerToys，也有一个叫  Window Hopper 的功能，可以提供类似的体验，

不过 PowerToys 目前太重了，我更喜欢 window-switcher 这样只有几百 k 的小工具。


window-switcher（切换窗口）
https://github.com/sigoden/window-switcher

## 5.bbplayer

有人基于某 B，开发了一个音乐 App，

只需要登录某 B 账号，

然后在某 B 种把喜欢的音乐视频，添加到收藏夹中，

或者订阅音乐合集，

bbplayer 中就能实时同步，像一个音乐软件一样舒服的听歌，

并且支持随意的把这些音乐，组合创建成本地歌单。


因为在某 B 上看视频基本都是免费的，

所以只要你能找到音乐的 MV 或者二创视频，就不需要任何会员想听什么就听什么。


bbplayer（听歌）
https://github.com/bbplayer-app/bbplayer

## 6.Index-Translate

某 B 开源了一套用于翻译的 Index-Translate 系列模型，

一共包含 2B、9B、35B 三个型号，支持 150 种语言，

尤其擅长翻译各种网络热梗。


除此之外，他们还基于翻译模型训练了三个衍生模型，

语音衍生模型支持六种语言，可以把一段语音，用同样的音色转换成其它语言，

长度控制衍生模型，可以指定翻译的长度，适合配音等需要控制长度的场景，

长文档衍生模型，可以拿来翻译长篇小说。


Index-Translate（翻译）
https://github.com/bilibili/Index-Translate
