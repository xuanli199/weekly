## 1.WechatOnCloud

作为一个国民软件，微信的痛点有什么？

占用空间大、多设备间不能消息同步、多开比较麻烦，这些肯定是排名比较靠前的。

而现在，一个开源的解决方案来了。

WechatOnCloud 是一个可以让我们把微信运行在 Docker 里，然后变成网页的开源项目。

之后，我们就可以随时在浏览器里访问它，

并实现同时登录多个微信账号，

不同的设备只要打开网页，就能共享同一个微信，且记录同步。

所有数据都被放在 Docker 里，

如果你有一个可以运行 Docker 的 NAS，

那么把它装在 NAS 上后，就不会再占用本机空间。

确保安全的情况下，把它装在服务器上，使用也会很方便。

之前我分享过一个叫 wechat-selkies 的开源项目，

同样能做到类似的事，

但是 wechat-selkies 比较初级，而 WechatOnCloud 要完善很多，

比如 文件传输 和 文本剪贴板 功能，

可以让我们非常方便的，在云端微信和本地电脑之间传输数据。

面板功能也能更加方便的管理会话，兼容不同架构的设备。

WechatOnCloud

https://github.com/Gloridust/WechatOnCloud

## 2.plain-app

这是一个可以让我们在电脑上，管理手机文件的开源工具，

同一个网络下，在手机上开启服务，

然后用电脑浏览器访问软件给的地址，

就能在网页上，看到手机上的所有音频、图片、视频、文档，以及所有的文件，

之后可以在线预览、下载、删除、重命名它们。

除了管理文件之外，还能通过屏幕共享功能，在线查看手机屏幕的画面，

向手机剪切板发送数据，远程控制手机打电话，

和手机聊天、发送文件。

我做视频的时候，经常需要在手机和电脑之间，传输各种素材，这种形式会非常方便。

plain-app用电脑管理手机文件

https://github.com/plainhub/plain-app

## 3.pinkbin

这是一个开源的 Windows 硬盘清理工具，

我们在清理电脑的时候，往往最大的两个问题是：

不知道是谁在占用硬盘、不知道文件夹是干什么用的，能不能删除。

现在 pinkbin 都给出了解决方案，

选择一个文件夹，点击扫描，

它会把文件夹中所有的内容从大到小排序，并清晰的显示出它的占比和大小，

让我们一眼就能看出来，每一个文件占用了多少空间。

之后，我们打开设置，输入一下大模型的 Key，

就能通过 AI 对话，来询问每一个文件夹的作用，以及能不能删除。

我的想法是：

这个项目的创意是很好的，但还是需要注意幻觉的问题。

pinkbin电脑清理

https://github.com/cccyd2003-qwq/pinkbin

## 5.PlayTranslate

这是一个开源的安卓游戏翻译工具，支持翻译 21 种语言，

它有自动模式和手动模式，

自动模式下，可以把对话直接翻译成指定的语言，

手动模式需要把光标拖到不认识的单词上，就能直接查看对应的意思。

PlayTranslate

https://github.com/dominostars/playtranslate
