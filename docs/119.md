## 1.BongoCat

BongoCat 是一个开源的互动桌宠，

打开之后，屏幕上会出现一个拿着鼠标键盘的小猫咪，

并且会跟随你移动鼠标、按下键盘的动作，做出相应的反应。


不过，它最初的版本早在多年前就已经停更了，

继任的版本也有五个月没有更新。


最近，Catime 的开发者把这只可爱的小猫桌宠，

完全重写了一遍，并加入了大量的全新特性。


首先改进最大的地方，我认为是资源占用，

因为整个项目是基于 C 语言的，所以占用小的可怕，

软件体积只有 5 MB，运行时内存不超过 20MB，CPU 几乎可以忽略不计。


第二是模型，

除了默认的小猫之外，它还支持自定义各种模型，

并且和多个模型师合作，在官网直接获取导入就能使用，

如果有需要，还可以私人定制。


在使用时右键点击模型，可以随时调整它的大小、动作、表情。


因为开发的时候，开发者在模型的动作方面花了很大的精力，

所以这一版的动作表现非常好， 

桌宠的视线会实时跟随鼠标移动，手部的动作也和用户的电脑操作完全一致，

互动流畅自然，即使同时打开八个桌宠，也非常和谐。


BongoCat（小猫桌宠）
https://github.com/vladelaina/BongoCat

## 2.DLSS5-Swapper

DLSS5 的画质增强官方版，目前只支持 50 系显卡，

但是民间版，已经覆盖到了 20、30、40 系，

甚至可以不管游戏是否兼容，就强行开启，最低能支持到 DX9，

使用起来也非常简单。


DLSS5-Swapper 就是其中的一个代表项目，

打开后选择一下要增强的游戏文件夹，

它会自动检测游戏的信息，并匹配合适的 DLSS 5 插件，

我们手动确认一下可执行文件和渲染 API 的版本是否正确，

点击下边的安装，所有配置就完成了，不需要的时候也可以在这里一键还原。


之后启动游戏，效果就会自动加载，

不过默认情况下，它的设置并不一定完全合适，

我们可以根据自己的需要，在玩游戏的时候按下 F8，或者 Home 键，手动调整效果。


DLSS5-Swapper（DLSS5 民间版）
https://github.com/rakanki911/DLSS5-Swapper

## 3.dlssg_for_sm86


DLSS5 的多帧生成官方版，目前只支持 50 系显卡，

但是民间版，已经覆盖到了 20、30、40 系，

使用起来也并不算很难。


RTX40MFG-Unlock 和 dlssg_for_sm86 就是其中的代表项目，

拿 dlssg_for_sm86 来说，

把仓库代码下载到本地，

然后按照 Readme 中的教程，

复制 代理 DLL 和 INI 文件，到游戏文件夹内，

然后按照自己的显卡，调整 INI 文件中的配置，就完成了安装。


启动游戏，在设置中就能找到插帧相关的配置了。


如果你正好对插帧感兴趣，或许会对你有用。


dlssg_for_sm86（插帧民间版）
https://github.com/dashdogy/RTX40MFG-Unlock
https://github.com/sdli1995/dlssg_for_sm86

## 4.MSFS-SimGPStoAndroid


这是一个可以把《微软模拟飞行》中，飞机的实时位置，

模拟到安卓手机定位系统上的开源项目。


完成配置之后，我们就可以使用高德导航开飞机了，非常有节目效果。


同时因为高德能识别到，用户并不是真的在导航，所以也不用担心会污染数据。



MSFS-SimGPStoAndroid（用手机导航开飞机）
https://github.com/JinShichang/MSFS-SimGPStoAndroid
