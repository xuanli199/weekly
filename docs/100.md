## 1.AngelSlim

腾讯混元开源了一个手机端离线翻译模型，

大小仅有 400M，支持 33 种语言，

同时具有比肩商用翻译模型的效果。

AngelSlim 是这个项目在 GitHub 上的代码仓库，

模型和手机 Demo 可以在 README 文档中找到，

如果你需要一个随时随地，在没网的情况下也能用的翻译工具，那或许会对你有用。

AngelSlim

https://github.com/tencent/AngelSlim

## 2.PLFM_RADAR

这是一个开源的硬件项目，

你可以通过它，非常低成本的搭建出来一个 10.5 GHz 的相控阵雷达系统，

项目一共有两个版本，分别可以探测 3 公里和 20 公里。

如果你对雷达感兴趣，可以拿来当学习资料，

动手能力比较强的话，还可以尝试把它做出来，但一定不要拿来做危险的事。

PLFM_RADAR

https://github.com/NawfalMotii79/PLFM_RADAR

## 3.dorso

我平时因为用电脑比较久，除了眼睛不舒服之外，

另一个很大的问题是不正确的坐姿，导致腰酸背痛。

dorso 是一个可以帮我们矫正坐姿的开源项目，

目前只适用于 Mac 电脑。

它可以通过 Mac 摄像头，或者 AirPods 运动传感器，实时监控我们的坐姿，

一旦像大虾一样，不自觉弯腰的驼背时，

电脑屏幕就会发出提醒，并逐渐变得模糊，回到正确坐姿之后才能恢复正常。

dorso

https://github.com/tldev/dorso

## 4.cassotis-ime

这是一个用于 Windows 的开源输入法，

对比各种商业输入法，

它完全开源免费，词库学习和各种数据都完全放在本地，

没有任何捆绑、广告、后台推送。

但反过来说，它的功能也比商业输入法要少很多，目前只支持纯粹的文字输入。

cassotis-ime

https://github.com/shenmin/cassotis-ime

## 5.warp

知名的 AI 终端 Warp 宣布开源，并在 GitHub 上放出了(客户端)所有源码，

这个项目早期，是一个比较好用的终端工具，

但是 AI 时代到来之后，它现在已经转换成了一个终端类的 Agent，

目前它仅仅开源几天，已经在 GitHub 持续霸榜，

对终端和 AI 感兴趣的可以试一下。

warp

https://github.com/warpdotdev/warp

## 6.social-auto-upload

这是一个适合自媒体创作者用的开源项目，

它可以帮我们把内容一键上传到各种自媒体平台，以及定时发布。

同时还有多个平台支持 Skill，可以让 AI 来调用，

所以也能用它搭配 AI 来做账号。

包括我在内的很多博主，在视频做完之后，都因为太麻烦，所以不想全平台分发，

使用这种自动化工具之后，就能省事很多。

social-auto-upload

https://github.com/dreammis/social-auto-upload

## 7.MicYou

最近发现了两个可以把手机，变成电脑外设的开源项目，

第一个叫做 MicYou，

可以把手机变成电脑的麦克风，

能通过 WiFi、USB 和蓝牙连接，

因为手机的麦克风一般都还行，所以大多数情况下，音质也都还不错。

如果你临时需要麦克风，

或者经常连麦玩游戏、开会，且有闲置旧手机，可以尝试一下。

第二个叫 AirMouse，

可以通过 WiFi，把手机变成临时的鼠标、键盘，手柄。

其实是把手机变成外设的类似工具还有很多，

比如 Spacedesk 可以把手机变成扩展屏幕，

AudioRelay 可以把手机变成音响等等。

所以没用的旧手机不要扔，万一有用呢？

MicYou

https://github.com/LanRhyme/MicYou

airmouse

https://github.com/cornradio/airmouse
