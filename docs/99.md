## 2.GithubStarsManager

如果你经常关注各种开源项目，

那么不知不觉间可能就 Star 了很多，以至于连自己都分不清它们的作用。

GithubStarsManager 是一个可以帮我们管理 Star 的工具，

打开之后输入 GitHub 账号的令牌，它就会获取到所有 Star 的项目，并把它们分类展示。

如果配置了大模型的接口，还能用 AI 对它们分析和搜索。

此外，如果你正在使用某个项目，还能使用它订阅项目的 Release，实时关注最新版本发布。

GithubStarsManager

https://github.com/AmintaCCCP/GithubStarsManager

## 4.tab-harbor

这是一个可以把浏览器新标签页，变成网页管理器的开源项目，

安装到浏览器上之后，新建一个标签页，

就能在这里看到当前浏览器打开了哪些网页，并且会按分组展示。

可以一键把它们关闭、收藏到稍后阅读，

还能创建待办事项，记录接下来要做的工作，当成一个 TODO 工具。

tab-harbor

https://github.com/V-IOLE-T/tab-harbor

## 5.ZenCrop

这是一个可以让我们剪裁 Windows 软件窗口的开源项目，

比如这是一个正在播放游戏攻略的浏览器，

我可以直接把中间的视频给剪裁出来，然后调整大小，挪到角落里，一边看攻略一边玩游戏。

ZenCrop 有几种不同的模式，有的模式可以让软件在剪裁后仍然能正常使用。

有的可以剪裁后调整大小。

在微软的官方开源项目 PowerToys 里，也有类似的功能，

不过 ZenCrop 占用体积更小，支持的软件也更多。

如果你有剪裁软件的需求，或许会对你有用。

zencrop

https://github.com/melody0709/zencrop

## 6.Caption-Trans

这是一个专为日语优化的视频翻译工具，

把要翻译的视频上传上去，

然后选择一个转录模型，软件会自动生成视频对应语言字幕，

接下来把字幕交给大模型，就能翻译成中文，

根据我个人的体验，转录时候使用 turbo 模型就完全够用了，

日语对中文的翻译，目前的主流大模型也完全能胜任。

Caption-Trans

https://github.com/cddqssc/Caption-Trans

## 7.Cardinal

这是一个开源的 Mac 文件搜索工具，类似 Windows 上 Everything，

输入想找的文件名字，它就会被瞬间找出来。

对比系统自带的聚焦搜索，Cardinal 搜出来的内容要更全，搜索结果展示的信息也更多。

并且它支持 Everything 的同款语法，

比如我要找 zip 格式，且文件名中有 “视频” 两个字的文件，就输入 *.zip 空格 视频，符合条件的就能全部找出来。

搜索大于 1000m，且文件名中有 “视频” 两个字的文件，就输入 视频 size:>1000m。

如果你在用 Mac，并且经常有搜文件的需求，或许能帮到你。

Cardinal

https://github.com/cardisoft/cardinal
