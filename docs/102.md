## 3.taken

当我们在浏览器上，访问一个网站时，

网站背后的运营者，都能看到我们的哪些个人信息？

有人制作了一个网站，很直观的进行了演示。

打开之后，它很轻松的获取到了我的 IP 地址，并判断出我所在的位置。

接下来是我所在的时区，以及我打开网址的时间，

网站可以用这些信息，轻易的判断出我的作息。

再往后是我用的电脑系统、屏幕大小、浏览器、使用的芯片、浏览器语言、字体信息、

这些独特的数据组合起来，就能形成电脑的数字指纹，精准追踪到人。

除此之外，它还能读取到浏览器是否接受 Cookie、是从哪个网址跳转过来的，切换到了其它网站多少秒，

鼠标移动了多少次等大量信息。

而这些信息，是每一个网站都能轻易读取到的，

如果是手机 APP，那么能获取到的更多，

这些内容放在一起，很容易就能分析出来你的方方面面。

不过，这个工具并不是在 GitHub 上开源的。

因为它只是一个简单的静态网页，所以按下 F12，就能拿走所有源码，网站的开发者也鼓励这么做。

taken

https://sinceyouarrived.world/taken

## 4.9router

如果你经常使用 AI 来辅助编程，

尤其是使用 Claude、Codex 等国外工具，

不但订阅价格贵，还会经常不够用。

如果开发复杂的项目，Token 很容易就会短时间内用完，

这时候要么咬牙上更贵的订阅，要么就只能等额度。

9Router 是一个开源的 AI 模型调度项目，

简单来说，它可以把市面上的各种模型，统一管理起来，并交给 AI 编程工具使用。

默认情况下，它会优先使用你订阅的昂贵套餐，

套餐用完后，自动切换成性价比高的国产模型，

再次用完后，切换成厂商提供的免费模型。

这样就能让你永远有 Token 可以使用。

除此之外，它内部还集成了一个省 Token 框架，

平均能省 20%-40% 的 Token。

9router

https://github.com/decolua/9router

## 5.camofox-browser

现在的 AI，已经拥有了操作浏览器的能力，

但是各大网站，并不希望自己的数据，轻易被 AI、爬虫给拿走。

所以开发了各种反爬虫机制，动不动就就要人机校验。

camofox-browser 是一个专门为 AI 开发的浏览器，

它直接在 C++ 层，对浏览器进行了魔改，

全面模仿了真人的各种指纹特征，可以绕过大多数浏览器的人机校验。

camofox-browser

https://github.com/jo-inc/camofox-browser
