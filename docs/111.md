## 2.wenyi

这是一个可以一键翻译长篇小说的开源项目，

支持 EPUB、TXT、PDF 等各种格式。

因为模型上下文的限制，

如果直接把长篇小说交给 AI 翻译，其实效果并不好。

文译使用了术语库、全书预扫、滚动上下文等多种手段，

尽量增强 AI 在翻译时候的一致性和质量。

如果你喜欢的外语书籍没有中文版，或者中文版翻译的不好，

而你又不想阅读原语言，或许它能够帮到你。

wenyi

https://github.com/BigDawnGhost/wenyi

## 3.grok-build

Grok 的新模型，和编程助手 Grok Build 上线后，

有人发现，Grok Build 会在使用的时候，偷偷上传用户的代码库，

在完成内部审查后，并调整了相关功能后，

马斯克为了打消用户的疑虑，决定直接把它开源。

现在项目代码已经在 GitHub 上开放，

作为一个大厂，项目的质量应该还是不错的，感兴趣的可以研究一下，

如果找到其中的问题，还可以去申请奖励。

除了 Grok Build，马斯克发出预告，

X 平台的代码也即将开源，值得期待一下。

grok-build

https://github.com/xai-org/grok-build

## 4.touch-grass

之前分享过很多个，在电脑上提醒休息的工具，

有很多人问有没有手机版本。

本周有观众投稿了他开发的 touch-grass，中文名 “咋还在刷”。

使用时，先给它打开无障碍服务，然后切换到 “监测” 模式，

它就会识别当前的界面是否为娱乐软件，

如果是的话，就在连续使用一段时间后，进行全屏提醒。

不过，目前它内置的规则还比较少，

如果你想要尝试，可以通过捕捉功能，手动标记你想要沉迷提醒的软件。

它使用起来也不难，

比如我现在想要制作某学习 APP 的规则，

可以在首页标记 “非短视频”，学习页标记 “短视频页”，

按同样的方式多标记几个界面，选择 “生成规则”，

之后在学习界面长时间停留的时候，软件就会弹窗提醒。

touch-grass

https://github.com/snownamida/touch-grass

## 6.optimizerDuck

这是一个开源的 Windows 优化工具，

它包含了性能、隐私、显卡、

电源、冗余软件、使用体验等六大优化类别，30 多个可优化项。

里边的部分项目，个人感觉还是很有用的，

比如这个 “优先分配前台应用资源”，就可以让前台的软件使用起来更流畅。

隐私设置中，可以关闭各种收集数据的遥测功能。

除了几大优化项，

optimizerDuck 还可以用来卸载没用的软件、清理硬盘的缓存、关闭软件的开机自启，

也都是比较实用的小功能。

optimizerDuck

https://github.com/itsfatduck/optimizerDuck
