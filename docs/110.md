## 1.viap

前段时间，

某办公软件会把缓存默认放在 C 盘，引起了很多人的讨论。

但其实，用户数据放 C 盘，是很多软件的默认设置，

比如像 Chrome、Edge 这些浏览器，

不但数据在 C 盘，还没有办法修改，并且可能会占用非常大。

viap 是一个可以帮我们解决这种问题的开源工具，

它的原理是先把软件的数据迁移到其他分区，

再使用 “软链接” 链接回 C 盘，

这样不但把数据挪走了，也不会影响软件的使用。

是目前我最推荐的清理 C 盘的方式之一。

类似的开源工具还有很多，

比如我之前推荐过的 NeatShif、FreeMove，

Mac 上也有 AppPorts。

不过需要注意的是，这类工具只适合移动 Users 文件夹下的内容，

也就是我们自己的用户数据，

千万不要动其它的系统文件夹。

viap（转移软件数据）

https://github.com/Chunyu33/viap

## 2.markeron

这是一个开源的轻量屏幕标注工具，

在电脑的任意界面，按下快捷键，

就能使用画笔、箭头、矩形、文字等 8 种工具，

在屏幕上绘制各种图案。

之后按下 w，可以一键切换到白板模式。

按下 x，电脑可以正常使用，且标注的内容不会消失。

如果你经常需要给人演示电脑屏幕、讲课，或许能够帮到你。

不过需要注意，

默认情况下，在退出标注后，所有内容就会消失，

如果你需要它们长期存在，就在设置中打开 “退出标注后保留”。

markeron（屏幕标注）

https://github.com/ifer47/markeron

## 4.health-tick-release

这是一个可以在我们连续使用电脑时，

定期提醒休息的开源项目，目前只支持 Mac 系统。

类似的工具我之前分享过好几个，

比如用于 Windows 的 Project Eye，

各种电脑系统都能用的 Stretchly，

我自己做的蟑螂提醒。

相比于它们，HealthTick 的主要亮点有两个，

一是可定制项非常丰富，

能让我们根据需要，

设置工作日、工作时间、免打扰时间。

自定义连续工作的时长、提醒休息的时长、每天的休息目标，

调整提醒的形式、提醒声音。

二是统计数据和成就系统，

可以让我们知道每天忙了多久、休息了多少次，并生成成就卡片分享给其它人。

health-tick-release（提醒休息）

https://github.com/lifedever/health-tick-release

## 5.playcaptcha

这是一个开源的验证码，

它使用了娃娃机的样式，

需要用户通过拨杆，把抓钩移动到指定的娃娃上方，

然后按下按钮把它抓起来，移动到出口并丢下去。

这个过程，验证用户是否是人类，

不管是形式还是操作都很有意思，感兴趣的可以把它放在自己的项目里。

playcaptcha（验证码）

https://github.com/mortspace/playcaptcha

## 6.exercises-dataset

这是一个全面的健身动作数据集，包含 1324 个动作，

每个动作都配备了动态图、缩略图等图像，

以及它们属于的分类、需要的器械、锻炼的部位等文字信息，

支持九种语言的分步指导。

直接把项目链接丢给 AI，几分钟就能开发出来一个健身的 APP。

不想动手的话，项目中也提供了一个 html 网页，用浏览器打开就能查看所有信息。

exercises-dataset（健身数据库）

https://github.com/hasaneyldrm/exercises-dataset
