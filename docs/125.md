## 1.bili-cli

本周，在平台上，出现了大量由 DeepSeek 自主运营的账号，

它们可以自己做视频、发视频、看视频、发动态、回评论、回私信、@主人。

bili-cli 是一个给 AI Agent 设计的 某 B 命令行工具，

它定制好了包括 看、互动、表态、创作、运营、汇报 在内的各种能力。

你可以通过它们，根据自己的喜好，定制一个自己专属的视频平台大肥鱼，

帮自己找好看的视频，或者让它自己开一个账号当 up 主。


我的想法是：

虽然 DeepSeek 很好玩，但是不建议大家用它大规模污染评论区，容易引起反感。


bili-cli（哔哩CLI工具）
https://github.com/kukemc/bili-cli

## 2.dsh-bili-scroll

bili-cli 是一个功能非常全面的工具，

而 dsh-bili-scroll，是一个专门用来让 AI 刷视频的 DeepSeek Harness 插件，

它会每天自己去 某 B 刷一轮视频，通过读字幕获取内容，

把值得看的写成报告，特别值得看的留一条评论，@我们 来看。


还可以设置只在 DeepSeek 的半价时刻跑，从而节省费用。


最近在某 B 评论区到处乱窜的大肥鱼，大概率就是它的杰作。


我的想法是：

虽然 DeepSeek 很好玩，但是不建议大家用它大规模污染评论区，容易引起反感。


dsh-bili-scroll（DeepSeek自动刷视频）

## 3.Mac.apk

这是一个可以让我们直接在 Mac 电脑上，原生运行安卓 APK 的项目，

软件会以 macOS 进程的形式启动，通用 Mac 的 CPU、GPU 执行，

会出现在 Dock 栏中，拥有自己的窗口，能调整大小和旋转，

跟随 Mac 的深色模型浅色模式自动切换。


我的想法是：

最近可能因为 AI 能力的提升，类似的项目大爆发，

比如这个叫 ios-topaz 的项目，

开发者把 iOS 系统，移植到了红米 Note 12 上，并实现了核心功能可用。


再比如这个 Snapintosh，

开发者在一台高通芯片的笔记本电脑上，成功运行起来了 ARM 版的 Mac 系统，

实现了 ARM 版的黑苹果。


不过，这些项目都处在比较早期的阶段，不管是兼容性还是稳定性都有待提升，

感兴趣的可以持续关注一下。


Mac.apk（Mac运行APK）
https://github.com/kksimp/Mac.apk
https://github.com/MakrSas/ios-topaz
https://github.com/Snapintosh/Snapintosh

## 4.gods-eye-view


这是近期 GitHub 最热门的项目之一，

开发者把它称之为间谍卫星模拟器。


打开之后界面上会显示一个这样的地球模型，

它接入了卫星、航班、传播、公开摄像头、街景、地震、天气等十几种数据，

打开开关之后，这些数据就会叠加到地球模型上。


我们可以通过放大缩小旋转地球，查看任意一个点的相关信息，最大可以缩放到街道级别。


可以选中某个航班、卫星，实时追踪它的位置，


通过摄像头功能，查看各种公开摄像到拍摄到的画面。


我的想法是：

它的功能很复杂，但我个人认为，除了好玩之外作用并不是很大，

不过或许会对你有用。


gods-eye-view（间谍卫星模拟器）
http://github.com/bilawalsidhu/gods-eye-view

## 5.cleanyourtv

一位博主使用 AI，彻底清楚了自己家里电视上的广告，

并给它刷了一个启动器，让电视的简洁和易用程度，提升了无数倍。

随后这条帖子爆火，获得了 800 多万观看，

在观众的强烈要求下，他把自己的操作流程开源了出来，

根据评论区的返图，目前已经有 170 多个不同的电视型号，成功使用它完成了电视清洁。

它不需要 root 权限，不需要数据线连接，不需要卸载任何软件，

只需要一个电脑，和一个 Agent 就能完成全部流程，

不需要的时候，可以一键还原回滚。


如果你也看家里的电视不爽，或许它能帮到你。


cleanyourtv（清理电视）
https://github.com/Gathin23/cleanyourtv
