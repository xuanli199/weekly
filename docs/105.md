## 1.ThreeFingerDragOnWindows

众所周知，Mac 的触摸板非常好用，

这其中的原因有很多，比如在拖动窗口、多选文字、文件时，

Mac 是把光标移动到标题栏，然后三指拖动，非常快捷好用。

而 Windows 是把光标移动到标题栏，然后快速轻按两下，

第二次时不要抬起手指，并在触摸板上滑动拖拽，体验就稍微差了一点，还容易和打开手势冲突。

ThreeFingerDragOnWindows，是一个能让我们在 Windows 上，使用三指拖动的开源项目。

优化之后，这个常用的操作，体验要好上不少。

ThreeFingerDragOnWindows触摸板

https://github.com/ClementGre/ThreeFingerDragOnWindows

## 2.AppPorts

众所周知，苹果的内存和硬盘寸土寸金，

如果你是一个 Mac 用户，但又不是无限购买预算，

那么你很有可能会遇到，硬盘不够用的问题。

想要解决这个问题也很简单，增加一块儿外接硬盘，然后把数据放进去。

但一般人，只会转移能看见的下载文件、文档、视频，而对软件产生的数据毫无办法。

AppPorts 是一个可以帮我们把软件数据，迁移到外接硬盘的开源项目。

但这里的迁移，并不是简单的帮我们复制文件。

比如像 Chrome，如果直接把它的数据剪切过去，

那软件根本不知道你把数据挪走了，还是会去原来的地方访问，

然后因为什么都找不到，所有的历史记录、Cookie、保存的内容都会消失。

剪切完数据，再增加软连接，同样会有很多兼容性的问题。

AppPorts 采用了独特的 Stub Portal 技术，

可以比较完美的帮我们把数据迁移到外置硬盘，尽可能小的影响使用体验。

如果你的 Mac 硬盘不够用，那或许能帮到你。

AppPorts Mac 把数据链接到硬盘

https://github.com/wzh4869/AppPorts

## 3.handwriting-web

输入一段文字，它就会生成一份这样的手抄文档，

把它打印出来，就得到了一份手抄稿。

还可以根据需要，调整不同的字体、纸张大小、背景图、间距、墨水深浅、是否涂抹等等。

精心调整一下，效果会和真实手抄的非常像。

handwriting-web告别手抄

https://github.com/14790897/handwriting-web

## 4.ian-xiaohei-illustrations

这个是一个可以帮我们给文章配图的 Codex skill，

它会抽象文章中的概念，然后生成出类似这种风格的图片，

个人感觉视觉效果很不错。

它目前有几种模式，可以直接丢给它一个文章，让它自己分析需要配图的地方，并生成图片，

也可以提供一个概念让它生成，

如果你是一个图文创作者，或许会有用。

中文小黑怪诞正文配图生成 Skill

## 5.coreutils

微软最近开源了一个新项目，

可以让我们在 Windows 上，使用 Linux 同款命令，

可以减少开发者切换不同系统时，熟悉环境和脚本改写的成本。

我的想法是：

习惯了 Linux 上的命令，再用 Windows 的确实很不习惯，

这个项目有一些用，但是目前只支持一些比较基础的命令，

希望微软能继续完善。

coreutils Linux 命令原生进入 Win11

https://github.com/microsoft/coreutils
