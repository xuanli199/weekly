## 1.Deskflow

这是一个可以让我们使用一套键鼠，就能控制多台电脑的软件，

之前因为家里桌子太小，不想放两套键鼠，

所以买了一个 KVM 切换器来解决问题，

但它并不算很方便，每次切换设备，都需要按物理按键。

于是我就找了一下有没有什么软件方案，

Deskflow 就是其中的一个，它使用起来非常简单，让两台电脑连接同一个网络，

把常用电脑设置成服务器模式，并记下来右上角的 IP，

在另一台电脑上选择客户端模式，输入刚刚的服务器 IP，

两台电脑就连接到一起了，

然后配置一下两台电脑的虚拟布局，比如我把 xuanli 放在右边，

使用的时候只需要把鼠标自然移出 Mac 的右边界，

它就会出现在 xuanli 这台电脑里，键盘也会随之切换过去。

想使用 Mac 电脑，把鼠标再从 xuanli 的左边移到 Mac 上即可。

这种使用方式，只要路由器配置还行，使用起来就会非常顺手流畅。

如果你也有多台电脑，但不想桌面上放那么多套键鼠，或许会对你有用。

目前类似的开源项目有很多，

input-leap、lan-mouse 这两个项目，也都能实现类似的效果。

我的想法是 ：

Deskflow 的 Windows 版本，需要一个依赖包，可以在 Readme 中找到。

Deskflow

https://github.com/Deskflow/Deskflow

input-leap

https://github.com/input-leap/input-leap

lan-mouse

https://github.com/feschber/lan-mouse

## 2.kiss-translator

这是一个开源的对照式翻译（浏览器）扩展，类似沉浸式翻译和陪读蛙，

这是一个纯英文界面，开启翻译过后，

它会把译文显示在英文下边，方便对照和查看，

它自带了谷歌、微软等一些免费的翻译接口，

也支持自己接入大模型和本地翻译。

我的想法是：

这种翻译扩展功能都差不多，找一个适合自己的就行了。

kiss-translator

https://github.com/fishjar/kiss-translator

## 3.CodexBar

这是一个可以让我们在 Mac 状态栏上，

查看各种 AI 用量的小工具，目前支持国内外各种服务商，

## 4.N.E.K.O

这是一个开源的桌面猫娘，

它拥有实时语音、和视觉理解功能，可以一边看屏幕上的内容，一边和我们聊天对话。

主动陪伴功能，如果不主动找她，她也会拿着网络热搜、好听的歌来主动找我们。

五维记忆系统，可以记下来我们和她的互动，

拥有丰富的插件生态，能陪我们玩各种游戏，当一个简单的生活管家。

Steam 版本支持创意工坊，能自定义形象、声音。

除此之外，这还是一个共创项目，如果你有想法，可以直接找开发者反馈讨论。

N.E.K.O

https://github.com/Project-N-E-K-O/N.E.K.O

## 5.FlowWheel

如果你在电脑上，经常看文档、小说，或者其它长内容，

那你可能需要频繁滑动滚轮，时间长了手指很容易酸，滚轮也容易坏，

在浏览器和记事本中，点击鼠标中键，能触发自动滚动功能，

只需要移动鼠标，就能向指定的方向移动页面，

但是其它软件，没办法实现类似的操作。

FlowWheel 是一个开源的 Windows 小工具，

可以给电脑增加系统级的自动滚动，

在任意软件按下鼠标中键，或者指定的快捷键，就能直接通过鼠标移动，滚动软件界面。

FlowWheel

https://github.com/humanfirework/FlowWheel
