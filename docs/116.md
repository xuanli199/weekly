## 1.DeepSeek Harness插件

DeepSeek Harness 仅仅发布了一周，插件生态就迎来了大爆发，

今天给大家分享一些我感觉比较有意思或者有用的。


在 GitHub 上目前有一个专门的插件分区 dsh-plugin，

收录了 1 万多款不同的插件，并且默认按 Star 数排序，应该是目前最齐全的，

但缺点是内容太多且没有专门的整理，整体质量参差不齐。

懒得自己一个个看的话，可以到 DSH Market 或者 Awesome DSH Plugin，

这两个网站里面都是由人工精选出来的优质插件，

并且会提供详细的介绍、分类、安装方式。


嫌窗口切换太麻烦，还可以使用插件 dsh-market，

它的功能是给 DeepSeek Harness 增加一个插件市场，

安装完成后在设置中打开插件市场，就能直接在线浏览、安装各种插件。


除了刚刚的插件市场一键安装之外，

我个人比较建议的方式是直接把仓库地址发给 DeepSeek Harness，

然后跟它说帮我安装一下，剩下的它会自动完成，我们只需要确认执行一下命令即可。

不想这么干，在仓库中一般也都会提供安装命令，复制到终端中执行就能完成安装，

碰到报错就找 DeepSeek 提问。


首先我要分享的并不是插件，而是客户端，

可以让我们不需要配置任何环境、执行任何命令，就零门槛用上 DeepSeek Harness。


电脑端目前最火的是 DeepSeek Harness Desktop，目前提供了 Mac 版和 Windows 版。

想要在手机端使用，我比较推荐 DSH Mobile APK 和 DSHA，

前者使用的是 Termux 运行时快照，后者使用的是 proot 加 Ubuntu，

基本上都做到了安装即用的效果。


第一个插件是 dsh-routing-suite，

这是一整套 DeepSeek Harness 增强工具，

它可以根据任务类型选择不同的推理模式，在运行时对模型做引导，尽量发挥出模型最大的能力。

最近这种类似提升 DeepSeek 能力的插件有很多，

每个插件使用的办法不一样，效果也不一样，

大家如果有需要可以都尝试一下，然后根据体验选择。


第二个是 dsh-agent-teams，

它的功能是可以让 DeepSeek Harness 拉起来一个互相配合的 Agent 团队，

当前的会话会成为队长，负责拆分任务、分配任务、汇总任务，

不同的 Agent 负责处理不同的任务。

团队创建完成后可以被保存下来，以后能随时复用。


第三个是 dsh-pocket，

它给 DeepSeek Harness 增加了远程使用的功能，有局域网、公网两种模式，

安装完成后在手机端扫码，电脑端的画面就能同步到手机上，

可以随时在手机查看任务进度、发送指令。


第四个是 dsh-context，

可以让我们通过可视化的方式，直观地看到当前的上下文每类内容占用百分之多少，

适合执行长任务的时候作为辅助。


第五个是 dsh-ads，

这是一个皮肤插件，可以给 DeepSeek Harness 增加一套国内画风的流氓广告。


第六个是 whale-girl，

一个拥有多种状态、可以互动的鲸鱼娘桌宠。


除了上面这几个，上周我分享过的 dsh-web-ui、dsh-TUI、

DSH-better-sidebar、dsh-anchored-standard，热度也都非常高。

## 2.CPURacer

这是一个可以让我们在任务管理器中开车的项目，

CPU 的性能曲线就是车的跑道，

按下 W 加油前进，按下 S 刹车后退，如果被甩出画面就会游戏失败。

虽然没什么具体的作用，但是很有意思。


还有一个类似的项目叫 copy-dialog-lunar-lander，

它的作用是让我们在拷贝一个大文件时，太无聊的情况下，在进度条里玩月球着陆器，

还可以根据复制的情况设置不同的难度。

简单难度是从一块硬盘拷贝到另一块硬盘中，

中等难度是把文件从电脑中拷贝到质量很差的 U 盘里，

困难难度是从遥远的大洋彼岸远程拷贝文件。


CPURacer（任务管理器开车）
https://github.com/CS-LX/CPURacer

copy-dialog-lunar-lander（拷贝进度条玩月球着陆器）
https://github.com/Sanakan8472/copy-dialog-lunar-lander

## 3.NanaZip

上周我分享了一个叫 7-Zip 的右键插件，很多观众给我推荐了这个叫 NanaZip 的项目，

这是一个基于 7-Zip 二次开发的压缩工具，全面适配了 Win11 的 UI 界面，

这是夜间模式，这是右键菜单，

提供了更多的个性化设置，以及多种哈希算法、编解码器。

如果你想要一个好用的压缩工具，但是不习惯 7-Zip 的复古界面，或许会对你有用。


NanaZip（压缩工具）
https://github.com/M2Team/NanaZip

## 4.insect-world

这是一个开源的 3D 昆虫图鉴，

包含 14 个目、63 个物种，

每一个都包含了它的介绍、一个可以互动的 3D 模型、

在不同生命阶段的状态、各种部位的放大视角、剖切和分层的视角。

如果你对虫感兴趣，或许会有一些帮助。


insect-world（3D 昆虫图鉴）
https://github.com/xr843/insect-world

## 5.ListextEditor

这是一个制作英语听力材料的工具，

它采用了搭积木的方式，

可以根据需要添加不同音色的中英文朗读、停顿、音效，

并在编排完成后导出为音频文件。

如果你是中学、小学的英语老师或者学生，

在没有合适的听力教材时，可以尝试一下。


ListextEditor（听力材料制作）
https://github.com/XiaoYangTech/ListextEditor
