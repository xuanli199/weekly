## 2.DeepSeek Harness


DeepSeek 在本周，开源了他们的 Agent 产品 DeepSeek Harness，

和之前的很多产品不一样，它使用了一种叫 “一切皆插件” 的理念。


简单来说，过去的 Codex 等工具，

会把所有的东西都封装好，用户能改的就只有 模型、Skill 等几项，

剩下的东西用户完全看不到，也改不了，安装好使用就行。


而 DeepSeek Harness，它默认只提供了灵魂功能，剩下的所有 Agent 能力，

包括模型、工具、技能、会话、沙箱、存储、循环、调度、UI，

都可以让用户像搭乐高一样，自己搭上去，能自由替换、灵活重组。


这么做有两个好处，一是会有很多大神，主动参与共建，做出来非常多好用的插件。

二是每个人都可以根据自己的喜好，定制出来最符合需求的 Harness。


但同时，缺点是会有一些上手门槛，

不过未来肯定会有各种定制版，来解决此问题。


同时，它的使用方式也和目前很多 toC 的工具不一样，

需要先安装 Node.js，然后执行启动命令，

项目会自动运行起来，并打开一个网页。


之后填写 DeepSeek 的 API，就可以使用了，

不想用 DeepSeek，也可以到设置中自定义其它模型。


默认情况下，DeepSeek Harness 已经自带了四个配置好的模式，

标准模式类似 WorkBuddy、Codex 这些工具，

官方已经配置好了完整的 Agent 需要的各种插件，可以上手即用。


PTC 模式和标准模式类似，

但可以模型生成一段代码来组合多轮工具调用，适合复杂的多步骤工作流。


极简模式仅保留了一个 shell 工具和一个文件编辑工具，

适合拿来测试模型的能力。


创造模式听名字就知道会非常自由，

它能自己构建、组合插件，并根据需要创造一个用户需要的新模式。


比如我可以在公司电脑上，

让它做一个调用本地模型，并接入公司系统的内部模式。

目前仅仅上线一天，网友已经玩出花了，GitHub 的 Star 也在暴涨，可见 GitHub 的号召力，


这里给大家分享一些目前比较高星的插件，

首先是 dsh-web-ui，这是一个 DeepSeek Harness 的插件、皮肤集合，

拥有任务看板功能，可以查看待办、进行中、已完成的任务，

鲸鱼娘桌宠，会根据智能体状态，自动切换思考、等待、工作等动作，能进行互动。

支持实时 Token 统计、移动端远程控制、

切换 Windows XP、我的世界、鲸吟等九款皮肤。



第二个是 dsh-TUI，

可以把 DeepSeek Harness，变成类似 Claude Code 的终端风格。


第三个是 dsh-better-sidebar，

可以把 DeepSeek Harness，变成类似 VSCode 的工作台，

内部集成了文件管理、文件预览、命令行终端、

Git、浏览器、窗口随意拖拽、后台任务等大量功能。


第四个是 modlens，

给 DeepSeek、GLM 等纯文本模型，补上了视觉的能力，

## 3.Android-Dex

这是一个可以让安卓手机，变成安卓电脑的开源项目，

在电脑上打开 Android-Dex 后，


打开手机开发者模式中的无线调试，或者 USB 调试，以及通过 USB 安装选项，

如果使用了无线调试模式，

需要在电脑端的 Android-Dex 中，输入手机上显示的 IP 地址和端口，

USB 调试需要用数据线，把手机和电脑连接到一起。


首次连接的时候，Android-Dex 会自动在手机上安装手机端 APP，

之后会自动启动 “安卓电脑”。


可以在这里，使用手机端的各种 APP，控制各种选项，

使用 APP 的时候，能像电脑系统一样拖动改变窗口大小、多任务并行。

支持同时连接多个手机。


它底层使用的是 scrcpy，流畅度还不错，

如果你有需要大屏使用手机的场景，或许能帮到你。



Android-Dex（安卓电脑）
https://github.com/Shrey113/Android-Dex

## 5.7-Zip_Context_menu_plugin


7-Zip 是一个开源的压缩软件，

我个人已经使用了很多年，非常喜欢，

想要压缩或者解压一个文件时，只需要右键点击文件，然后在菜单中选择  7-Zip 即可。

但是更新到 Win11 后，微软把传统的右键菜单折叠了起来，

想使用就要多点一下，或者按着 Shift 再点右键，稍微有一些不方便。


7-Zip_Context_menu_plugin 是一个开源的插件，

可以把 7-Zip 的菜单，添加到一级菜单里，使用起来就方便了很多。


7-Zip_Context_menu_plugin（7-Zip插件）
https://github.com/Wings-Fantasy/7-Zip_Context_menu_plugin

## 6.trash-cli

在 Linux 系统上，删除文件一般使用 rm 命令，

但它是一个永久删除命令，执行之后文件就会彻底消失，没办法恢复。

有时一不小心删错，就会造成惨痛的后果。


trash-cli 是一个在删除时，默认把文件移动到回收站的开源工具，

同时会记录文件的原地址、删除日期和权限。

支持随时恢复，或者确认没用后彻底删除。


和 Windows、Mac 上回收站体验一致，相当于给了一个后悔药。


trash-cli（带回收站的删除）
https://github.com/andreafrancia/trash-cli
