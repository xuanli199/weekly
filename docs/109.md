## 1.chinese-poetry-api

这是一个开源的中国古典诗词 API 服务，

其中收录了唐诗、宋词、元曲等各类诗词 37 万首，

涵盖李白、杜甫、苏轼等 130000 多名诗人，11 个朝代、17 种题材。

我们可以通过它提供的 API，

随机获得一首诗、

搜索某个诗人、

也可以多条件综合查询、全文搜索、获得各种统计数据。

如果你想要做古诗相关的软件，它或许能提供一些帮助。

不想用 API 的话，

这个项目的数据，全都来自另一个叫 chinese-poetry 的项目，

所以，也能直接通过它，

把几十万首中国古典诗词，全部下载到本地，导入自己的数据库，

想怎么用就怎么用。

chinese-poetry

https://github.com/chinese-poetry/chinese-poetry

chinese-poetry-api

https://github.com/palemoky/chinese-poetry-api

## 2.PriceAI

这是一个开源的 AI 订阅比价工具，

包含卡网订阅、官方订阅、官方 API、中转 API 等各个渠道。

比如像官方订阅，

它会从 App Store 获取 AI 在各个区域的价格，然后从低到高排序，

一眼就能看到哪里更便宜。

再比如中转 API，

可以看到不同中转站的综合倍率、稳定性、来源渠道等信息，

在订阅 AI 之前看一眼，或许能找到价格最适合你的渠道。

priceAI

https://github.com/physics-dimension/PriceAI

## 3.voicebox

这是一个开源的 AI 语音工具，

它集成了目前开源的各种语音模型，

可以让我们很方便的通过一段样本，把声音克隆下来。

之后，我们就能用克隆好的声音，

直接朗读一句话。

或者通过故事功能，拿来配小说、广播剧。

除了语音生成之外，voicebox 还有声音处理能力，

生成完后可以当场做后期，效果不满意就重新生成调整，

一个工具，就能自己在家搭建一个虚拟的声音工作室。

voicebox

https://github.com/jamiepine/voicebox

## 5.OpenBiliClaw

不知道你有没有感觉到，

某 B、某抖、某书，这些算法驱动的平台，

经常会越刷越空虚，越刷越无聊，

有时还给你推送一些根本不感兴趣、不想看的内容，

就算点了不喜欢和拉黑都没有用。

这是因为，算法往往是平台决定的，

而平台的最终目的，并不是让你看到最喜欢的东西，

而是让平台的留存、使用时间这些数据变得更好看。

OpenBiliClaw 是一个可以帮我们，发现更多好看内容的 AI 工具，

它的原理是通过一个浏览器扩展，获取我们经常在各大平台看的视频和文章，

然后把这些数据，发送到运行在本地的后端，综合起来分析理解，

生成一个标签非常齐全的兴趣画像。

之后根据获取到的画像，

去跨平台搜索我们大概率感兴趣的内容，展示到一个网页上。

并且，在使用的时候，

它会反复通过我们的反馈、或者主动提出的要求，去更改画像，获取不同的内容。

我的想法是：

它的数据存储和处理，都是通过我们电脑上的后端进行的，

加上项目代码是开源的，可以自己打包，

所以不用太担心隐私的问题。

我自己试用了一下，推荐的内容确实很不错。

并且它有跨平台的效果，

以前在 A 平台喜欢看科技，B 平台喜欢看搞笑，两边的算法互相不知道，

现在有了本地的综合算法，会有一种意想不到的效果。

openblliclaw

https://github.com/whiteguo233/OpenBiliClaw
